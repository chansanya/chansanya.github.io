Docker镜像

# 参考

  • 基于hubproxy (opens new window) 搭建

# Docker镜像：

docker pull proxy.10085.fun/user/image

# ghcr.io 镜像：

docker pull proxy.10085.fun/ghcr.io/user/image

# Quay.io 镜像：

docker pull proxy.10085.fun/quay.io/org/image

# K8s 镜像：

docker pull proxy.10085.fun/registry.k8s.io/pause:3.8

# 一键设置镜像加速

修改文件 /etc/docker/daemon.json（如果不存在则创建）

# 创建目标路径

sudo mkdir -p /etc/docker

# 新建daemon.json文件

sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://proxy.10085.fun"]
}
EOF

# 重新加载并重启

sudo systemctl daemon-reload && sudo systemctl restart docker
