虚拟机磁盘扩展

# Ubuntu

查看所有卷组:

vgdisplay

查看所有逻辑卷：

lvdisplay

或者

lvdisplay

扩容逻辑卷:

# +100%FREE：使用 LVM 中所有剩余空间。
# /dev/ubuntu-vg/ubuntu-lv 是你的逻辑卷路径（可通过 lvdisplay 确认）
sudo lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv

扩展文件系统:

# 如果是 ext4
sudo lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv

# 如果你用的是 xfs
sudo xfs_growfs /

查看效果：

df -Th /
